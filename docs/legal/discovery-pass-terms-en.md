## 1. What the Discovery Pass Is

- The Discovery Pass is a **fixed, prepaid fee of 1,000 NIS**. Prepaid or subscription
  billing only — no invoicing on credit.
- It buys one guided requirements-discovery session with the Discovery Studio AI
  agent (text/chat, English or Hebrew).
- If the project is onboarded with GranitCorp, the full 1,000 NIS is **fully
  credited** toward the project cost.
- Optional live deep-dive session directly with Guy: **500 NIS/hour**. If the
  project is onboarded, **50% of that fee is credited** toward the project cost.
- Payment and invoicing are handled **manually** for now.
- The Discovery Pass covers requirements discovery only — **no coding, development,
  or implementation work** is included.
- No customer account or password is created or stored for this service. Access is
  via a one-time PIN issued by GranitCorp (Cloudflare Access).

## 2. AI-Use Disclosure

- This session is conducted by an **AI agent** ("Discovery Studio"), not a human,
  unless and until you are handed to Guy for the paid live deep-dive.
- The agent can make mistakes, misread what you type, or produce an incomplete
  summary. It does **not** provide legal, financial, tax, or other professional
  advice.
- Every output (requirements summary, draft quote) is **reviewed by Guy** before any
  quote or commitment is finalized.
- The agent has **no access** to GranitCorp's internal "AI1" systems or data.
- This service is currently **text/chat only** — voice is not supported.
